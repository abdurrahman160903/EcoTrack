# EcoTrack: Environmental Impact Tracker
This project aims to help users track their environmental impact in a comprehensive and user-friendly way. Using advanced technologies, EcoTrack will provide data-driven insights to encourage sustainable living.

## Features
- Track carbon footprint
- Monitor waste management
- Analyze eco-friendly habits

## Getting Started
To get started with the app, follow these steps:
1. Clone the repository
2. Open the project in Android Studio
3. Build and run the application

## Technologies Used
- Kotlin
- Android Jetpack
- Room Database
- Retrofit
- MVVM Architecture
